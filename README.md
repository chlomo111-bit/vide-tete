# Vide-Tête

L'appli de tâches de Shlomo : un micro pour vider sa tête, une seule liste rangée par domaine (Photo, Restaurant, Jeux Instagram, Vidéo, Applis & sites, Perso / admin), des routines et des suites automatiques.

- Appli en ligne : https://claude.ai/artifact/PmxgN6yR3Zwpm9AoFq2KC9
- `index.html` : le code de la page, copie de sauvegarde.

La page tourne dans Claude : les tâches, le tri automatique et le micro passent par Claude. Ouverte en dehors de Claude, elle s'affiche mais n'enregistre rien.
